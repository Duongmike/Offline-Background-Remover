# Security policy

## Supported versions

Security fixes are applied to the latest published release and the `main`
branch. Older local builds are not supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use **Report a vulnerability** in the repository's GitHub Security tab to send
a private report. Include the affected version, reproduction steps, expected
impact, and any suggested mitigation. Reports will be acknowledged as soon as
practical, then assessed before public disclosure.

Do not include private user images or credentials in a report. Use a synthetic
test image whenever possible.
