# Quality regression dataset

The checked-in `starter` set contains eight original, deterministic synthetic
fixtures generated by `scripts/generate_quality_starter.py`. The inputs and
ground-truth masks are dedicated to the public domain under CC0-1.0.

The starter set verifies the evaluation pipeline and catches large alpha-mask
regressions. It is **not** evidence of real-world background-removal quality.
Real photographs must only be added when redistribution rights, attribution,
subject consent where applicable, and an explicit model/dataset license have
been reviewed.

Generate the starter set:

```powershell
.venv\Scripts\python.exe -m scripts.generate_quality_starter
```

Run one reproducible model pass and write a JSON report:

```powershell
.venv\Scripts\python.exe -m image_tool.quality `
  --manifest quality_dataset\starter\manifest.json `
  --predictions quality_results\starter-u2netp `
  --run-model u2netp `
  --output quality_results\starter-u2netp.json
```

Reports include MAE, SAD, IoU, F1, provider, platform, Python version, and
per-case stage timings. Do not compare performance reports unless the model,
dataset, provider, hardware, and cold/warm conditions match.
