# Support

Use GitHub Issues for reproducible bugs and feature proposals. Before opening an
issue, search for an existing report and run the latest available version.

Include the application version, Windows version, CPU/GPU, selected removal
mode, active ONNX provider shown by the app, and minimal reproduction steps.
Attach only images you have permission to share.

Security vulnerabilities must be reported privately according to
[`SECURITY.md`](SECURITY.md).
